Input format and instruction reference

$AMJ begins a job; the following 14 digits are job ID (4), time limit (4), line limit (4), and priority (2). Lower priority numbers run first. Program lines contain four-character instructions. $DTA begins data lines and $END ends the job.

Instructions: LRnn load a word, SRnn store the register, CRnn compare, BTnn branch if equal, GDnn read a data block, PDnn print a block, H halt.

Simulator note: the browser uses a simplified virtual memory and simulated I/O model for teaching. It parses the same job deck, but does not execute the C++ kernel itself.
